# Sleep-Disorder

## Deskripsi
Proyek ini bertujuan untuk menganalisis faktor-faktor yang memengaruhi kualitas tidur menggunakan EDA dan mengidentifikasi pola dalam dataset melalui metode Machine Learning.

## Tools
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Hasil
Hasil dari projek ini agar memberikan pemahaman lebih mendalam tentang faktor-faktor yang mempengaruhi gangguan tidur
